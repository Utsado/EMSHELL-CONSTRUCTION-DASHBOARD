# MSHELL Construction – Power BI Dashboard

A multi-page Power BI dashboard built on a custom Nigerian construction dataset, 
simulating real-world project cost tracking and performance analysis.

## Overview
- **372 construction projects** across multiple Nigerian locations
- **₦2.91bn** total budgeted cost | **₦3.01bn** actual cost
- **₦102.31M** total cost variance

## Dashboard Pages
- **Overview** – KPI cards, project status donut, cost category bar chart
- **Project Performance** – Status by manager, cost variance by manager (donut), 
  budget vs actual scatter plot

## Features
- Interactive slicers: Project Manager, Project Status, Location
- DAX measures: Budget vs Actual, Cost Variance, Completion %
- Data modeling with relationships across project and cost tables

## Tools Used
Power BI | DAX | Data Modeling | Excel

## Dataset
Custom Nigerian construction dataset built for portfolio purposes.
